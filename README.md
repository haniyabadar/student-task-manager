# Student Task Manager
A Python console app to manage student tasks.
Project status: In Development

## Features
- Add, display, complete and delete tasks
- Input validation (no empty titles)
- Unit tests with GitHub Actions CI

## Setup
git clone https://github.com/haniyabadar/student-task-manager.git
cd student-task-manager
Requires Python 3.10 or newer. No extra packages are needed.

## Usage
python main.py

## Run Tests
python -m unittest discover -s tests -v
